# Security status

This repository is a **prelaunch demo**, not a deployed lending application.

- No user deposits or borrowing; do not send funds or grant token approvals to the prototype.
- The sample custody contract is NOT audited and NOT designed for production.
- Wallet screenshots and DEX quotes do not demonstrate collateral liquidity.
- Protocol integrations, supported deployment, oracle, funding and liquidation risk remain unverified.
- No private keys, RPC credentials, mnemonics or API secrets should be committed.

Report security vulnerabilities privately to the repository maintainers.
